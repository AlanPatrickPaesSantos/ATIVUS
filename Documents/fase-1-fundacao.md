# Fase 1 — Fundação do projeto

## Objetivo

Criar uma base mínima, separada e executável para frontend e backend, sem antecipar regras de negócio.

## Entregas iniciais

- Estrutura `frontend/` e `backend/`;
- Backend HTTP mínimo;
- Frontend mínimo;
- TypeScript configurado no backend;
- Scripts de desenvolvimento, build e execução;
- Separação inicial da documentação técnica.

## Próximas decisões da Fase 1

- Dependências definitivas do backend;
- Dependências definitivas do frontend;
- Configuração do MongoDB;
- Variáveis de ambiente;
- Padrão de lint e formatação;
- Testes automatizados;
- Estratégia de execução local.
